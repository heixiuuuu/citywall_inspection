# 小程序 UI 设计规范（design tokens）

> 开发 `miniapp/` 时以此为唯一视觉规范。rpx 为小程序单位（750rpx = 屏宽），px 为设计稿基准（375 宽画布，1px = 2rpx）。

## 1. 色彩

### 1.1 品牌色（城墙意象）

| Token | 值 | 用途 |
| --- | --- | --- |
| `brand` | `#2F6F63` | 主操作按钮、选中态、链接 |
| `brand-dark` | `#25584F` | 主按钮按压态、顶部导航背景 |
| `brick` | `#B5543A` | 强调/警示点缀（识别候选确认） |
| `ink` | `#2B2B2B` | 主文本 |
| `ink-secondary` | `#6B6B6B` | 次级文本 |
| `ink-faint` | `#9B9B9B` | 占位/说明文本 |
| `wall` | `#F5F1E8` | 页面背景（米白，城墙砖色基调） |
| `card` | `#FFFFFF` | 卡片背景 |
| `line` | `#E6E1D5` | 分隔线/描边 |

### 1.2 状态色（全局统一，跨端一致）

| 状态 | 值 | 语义 |
| --- | --- | --- |
| DRAFT / 待采集 | `#8A8A8A` | 灰 |
| ASSIGNED / 已派发 | `#3B82C4` | 蓝 |
| IN_PROGRESS / 采集中 | `#C98A2D` | 琥珀 |
| SUBMITTED / PENDING_REVIEW / 待审核 | `#7A5BC6` | 紫 |
| ACCEPTED / COMPLETED / 已完成 | `#3E9B5B` | 绿 |
| RETURNED / REJECTED / 退回驳回 | `#C4453C` | 红 |

规则：状态标签 = 色值 12% 透明度底 + 色值文本；主流程推进按钮使用 `brand`。

## 2. 字体与字号

| Token | rpx | px | 用途 |
| --- | --- | --- | --- |
| `text-xs` | 22 | 11 | 标签/徽标 |
| `text-sm` | 26 | 13 | 辅助说明 |
| `text-base` | 28 | 14 | 正文 |
| `text-lg` | 32 | 16 | 卡片标题 |
| `text-xl` | 36 | 18 | 页面标题 |
| `text-2xl` | 44 | 22 | 数字/金额类强调 |

字重：正文 400；标题/按钮 500–600；数字 600。行高 1.4–1.5。

## 3. 间距 / 圆角 / 阴影

- 页面左右安全边距：24px（48rpx）；卡片间间距 12px（24rpx）。
- 圆角：卡片 12px（24rpx）；按钮 8px（16rpx）；标签 4px（8rpx）。
- 阴影：卡片 `0 2px 8px rgba(43,43,43,.06)`；底部操作栏 `0 -2px 8px rgba(43,43,43,.04)`。

## 4. 组件规范

| 组件 | 规范 |
| --- | --- |
| 主按钮 | 高 44px（88rpx），品牌色填充，圆角 8px，全宽 95% 左右居中；禁用态 40% 不透明度 |
| 次按钮 | 白底 + 1px 品牌色描边，文字品牌色 |
| 状态标签 | 高 20px（40rpx），圆角 4px，色值 12% 底 + 同色文本，字号 11px |
| 任务卡片 | 白底圆角 12px：标题行（标题 + 状态标签）、信息行（点位数量 · 负责人 · 截止日期）、右侧箭头 |
| 点位列表项 | 序号圆点（品牌色描边，序号数字）、快照名称、位置提示、右侧状态标签；整卡可点 |
| 图片上传格 | 3 列网格；每格 96×96px；已传图右上角 20px 圆形删除钮；概览图需至少 1 张（提交校验） |
| 单选组（现场判断） | 4 等分胶囊按钮：正常/疑似/不确定/不可达，选中态品牌色底白字 |
| 底部操作栏 | 固定底栏高 64px：主按钮 + 次要文字（如"提交任务（3/3 已完成）"） |
| 筛选 tab | 胶囊横滑：待处理/进行中/已完成；选中态品牌色底白字 |

## 5. 图片与识别展示

- 概览图（OVERVIEW）必须 ≥1 张；细节图（DETAIL）可选多张。
- 识别结果区：原图 + 半透明候选框（赭红描边 2px，右上角 class_code + 置信度标签），底部"检测到 N 个候选"说明行 + 按钮"重新识别"。
- 人工结论区：以"结论项列表"呈现（每项：图片缩略 + 决策标签[确认/修改/删除/补录] + 病害类别 + 描述），编辑态整体可增删改，与 PUT conclusion 的 items 一一对应。

## 6. 无障碍与触控

- 最小可点区域 44×44px；按钮/卡片不叠加文字遮挡。
- 状态色同时以文字标注（不依赖纯色识别）。
- 弱网/失败态：识别失败显示错误码（RECOGNITION_TIMEOUT 等）+ 重试按钮，不阻塞人工结论填写。
