# 小程序 UI/UE 设计（台州府城墙病害巡检）

> 依据 01《需求与项目边界》与 02《核心业务流程》：巡检员在微信小程序中接收任务、到点采集证据（照片 + 位置 + 现场判断）、调用视觉识别获得候选、填写人工结论并提交；审核员在管理端审核。本目录先统一 UI/UE 设计，再进入 `miniapp/` 开发，开发时以本文档与高保真原型为唯一视觉规范。

## 1. 设计范围与角色

| 角色 | 端 | 页面 |
| --- | --- | --- |
| 巡检员 | 微信小程序 | 登录、我的任务、任务详情、现场采集、主动上报 |
| 审核员 | PC 管理端 | 待审核列表、审核详情（设计见 web/ 阶段） |

小程序不承担审核操作（与 03 文档权限模型一致：审核在 PC 端完成）。

## 2. 信息架构与导航

```
登录页
  └─ 我的任务（首页）
       ├─ 任务详情 ── 现场采集（拍照 → 识别 → 人工结论 → 提交）
       └─ 主动上报（任务外采集，入口在首页）
```

页面切换：
- 登录成功 → 首页（微信身份映射 test-inspector 等，MVP 不强制账号密码）。
- 首页任务卡片点击 → 任务详情。
- 任务详情点位卡片"去采集"→ 现场采集（仅当前巡检员可采集；已提交/已通过点位不可重复采集）。
- 首页右上"＋ 主动上报"→ 主动上报页。

## 3. 设计原则

1. **一步一屏**：采集流程按"拍照 → 识别 → 结论 → 提交"四步在同一页内纵向推进，避免跳页丢失上下文；关键动作（提交）置于页面底部固定栏。
2. **状态可见**：任务点状态、提交状态在列表与详情两级均用统一色标表达（见 ui-spec.md §3）。
3. **城墙意象**：配色取自台州府城墙（砖灰 / 赭红 / 米白），区别于通用管理系统的蓝白风格，突出主题一致性。
4. **触控目标**：主按钮高度 ≥ 44px（rpx 88），可点击卡片整卡可点，返回按钮固定。
5. **弱网优先**：MVP 不引入地图 SDK，位置以「自动定位文本 + 手动修正文字」表达；图片压缩与上传进度在小程序端处理。

## 4. 页面清单（MVP）

| # | 页面 | 核心元素 | 关键交互 |
| --- | --- | --- | --- |
| P1 | 登录 | Logo、微信一键登录、测试身份提示 | 点击登录 → 调 /auth/wechat-login |
| P2 | 我的任务 | 用户栏、状态筛选 tab、任务卡片列表 | 筛选切换；卡片点击进入详情；右上"主动上报" |
| P3 | 任务详情 | 任务信息卡、点位列表（序号/快照/状态）、底部提交任务按钮 | 点位卡片点击进入采集；全部点位完成后可整任务提交 |
| P4 | 现场采集 | 概览图/细节图上传区、位置卡片、现场判断单选、识别结果区、人工结论区、提交 | 拍照/选图；触发识别；编辑人工结论；提交（校验概览图+结论+位置） |
| P5 | 主动上报 | 位置、描述、照片、结论、提交 | 与 P4 结论/图片区复用，无任务关联 |

高保真原型见 `high-fidelity.html`（浏览器打开，375×812 模拟 iPhone 12 mini 视口，可切换页面预览）。

## 5. 与后端契约的对应（开发检查表）

- 登录：`POST /api/v1/auth/wechat-login {code}` → `{token, user, roles}`；MVP 固定 code：test-inspector。
- 我的任务：`GET /api/v1/tasks`（按当前用户过滤）。
- 任务详情：`GET /api/v1/tasks/{id}` → `{task, points}`。
- 现场采集：
  1. `POST /api/v1/observations {source:TASK, task_point_id, location_text}` → observation id；
  2. `POST /api/v1/observations/{id}/images`（multipart：image + image_role=OVERVIEW/DETAIL）；
  3. `POST /api/v1/images/{imageId}/recognitions` → attempt + detections（候选，仅作参考）；
  4. `PUT /api/v1/observations/{id}/conclusion {revision, outcome, items}`；
  5. `POST /api/v1/observations/{id}/submit {revision}`。
- 主动上报：同采集流程，`source:VOLUNTARY`，不传 task_point_id。
- 图片展示：`GET /api/v1/images/{id}/content`（带 token，不落公开目录）。
