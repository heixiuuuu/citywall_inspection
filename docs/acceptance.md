# 验收范围与边界

## 软件能力

| 模块 | 当前实现 | 必须核验的外部条件 |
| --- | --- | --- |
| 业务后端 | 登录、角色、档案、任务、记录、审核、问题、报告、审计 | MySQL 迁移及受控文件目录可读写 |
| 管理端 | 档案维护、任务派发、照片与候选框、修订与审核意见、处置及报告 | 浏览器中的操作与接口数据一致 |
| 巡检端 | Android APK、账号登录与恢复、系统拍照上传、任务分页、定位采集、逐图识别与叠框、候选判定、草稿保存、结果查询及退回补正 | 实机定位精度、相机成像和现场网络 |
| YOLO | 图像校验、类别校验、真实推理适配、失败尝试保存 | 专用病害权重及独立测试集评估 |
| 视觉语言模型 | 图像请求、结构化分析、异常隔离、结果存储与展示 | 可用模型服务、模型名称及凭据 |

Go 单元测试、管理端构建、巡检端资源构建、识别接口替身测试与业务联调分别验证不同层次。不能将替身测试、编译成功或接口返回成功作为病害识别准确率、真机使用效果或模型辅助分析质量的证据。

定位链路校验有效数值、经纬度完整性和零坐标；任务偏移使用派发时的目标坐标及提示半径。验收覆盖点位档案变更、退回补正、提交快照不变性，以及记录和报告同时展示距离超限与低精度提示。球面距离用于人工复核提示，实际定位精度仍需现场验证。

## 数据与模型

数据转换以 MSD-dataset.zip 中的 VOC 标注为输入，支持裂缝、变色、泛碱、表面溶蚀、砌体单元缺失、苔藓、植物七类标注。HEIC 需要 pillow-heif。manifest.json 保存数据来源、哈希、划分、各类框数、方向归一和跳过原因。通用类别字典中无标注的类别不属于该数据集已训练能力。

表面剥落使用独立类别 SURFACE_SPALLING，可自动产生候选并由巡检员复核或补录。剥落权重使用 CIF 的独立 Spalling 标注，训练场景主要是现代基础设施，不将 MSD 的表面溶蚀或青砖来源的 W_E 标签视为剥落。局部验证集含 101 张裁剪图和 216 个标注框，mAP50 为 0.220；以 0.25 置信度对 6 张原始验证图进行分块识别，得到 4 个匹配、19 个误检和 8 个漏检。这些样本不足以代表古城墙现场效果，剥落候选必须人工确认，现场准确性尚未验证。

按内容哈希去重并划分能避免完全相同图片跨集合；同一墙段的相近图像仍需按采集场景复核分组，不能据此声称消除了场景泄漏。正式实验需核对类别语义、授权范围、场景分布，并补充实际城墙样本。

实际权重、训练记录、测试集指标和样例检测图是模型验收的必要交付。仓库中的模型适配器与训练命令不能代替这些产物。

当前可转换的样本为 1,076 张：训练集 860 张、验证集 114 张、测试集 102 张，位于 data/yolo/dataset_msd_oriented。134 张图片的标注尺寸与 EXIF 方向归一后的尺寸一致，已按该坐标系转换；原有 942 张的划分、图片字节和标签保持一致。6 个图片引用无法匹配，1 个无效框被排除。上述统计描述数据转换结果，不是模型评估指标。

当前部署的 yolo_routed_msd_spalling_001 使用三份 YOLOv8n 权重。主模型和裂缝专项模型的置信度为 0.35，分别使用 640 和 960 输入；裂缝、泛碱和苔藓采用专项模型。剥落模型采用 0.25 置信度和 1280 像素分块，其余类别采用主模型。权重、哈希及类别分工位于 data/yolo/weights。

在方向归一后的 102 张 MSD 测试图、732 个标注框上，主模型和裂缝专项模型组合按整数坐标、置信度排序、同语义类别及 IoU 至少 0.5 的一对一匹配规则输出正确匹配 134 个、误检 228 个、漏检 598 个，Precision 为 37.02%，Recall 为 18.31%，F1 为 24.50%。该结果不包含剥落模型，是固定运行阈值的微平均指标，不是标准 mAP 指标。测试数据和成员指纹、逐类结果及本机 CPU 耗时保存在 data/yolo/runs/routed_msd_001/evaluation-runtime-test.json。漏检、类别混淆和定位仍是主要短板，识别质量尚不能据此认定通过现场验收。
