# 验收范围与边界

## 软件能力

| 模块 | 当前实现 | 必须核验的外部条件 |
| --- | --- | --- |
| 业务后端 | 登录、角色、档案、任务、记录、审核、问题、报告、审计 | MySQL 迁移及受控文件目录可读写 |
| 管理端 | 档案维护、任务派发、原图与候选框、修订与审核意见、处置及报告 | 浏览器中的操作与接口数据一致 |
| 巡检端 | Android APK、账号登录与恢复、系统拍照上传、任务分页、定位采集、候选判定、草稿保存、结果查询及退回补正 | 实机定位精度、相机成像和现场网络 |
| YOLO | 图像校验、类别校验、真实推理适配、失败尝试保存 | 专用病害权重及独立测试集评估 |
| 视觉语言模型 | 图像请求、结构化分析、异常隔离、结果存储与展示 | 可用模型服务、模型名称及凭据 |

Go 单元测试、管理端构建、巡检端资源构建、识别接口替身测试与业务联调分别验证不同层次。不能将替身测试、编译成功或接口返回成功作为病害识别准确率、真机使用效果或模型辅助分析质量的证据。

## 数据与模型

数据转换以 MSD-dataset.zip 中的 VOC 标注为输入，支持裂缝、变色、泛碱、表面溶蚀、砌体单元缺失、苔藓、植物七类标注。HEIC 需要 pillow-heif。manifest.json 保存数据来源、哈希、划分、各类框数和跳过原因。通用类别字典中无标注的类别不属于该数据集已训练能力。

按内容哈希去重并划分能避免完全相同图片跨集合；同一墙段的相近图像仍需按采集场景复核分组，不能据此声称消除了场景泄漏。正式实验需核对类别语义、授权范围、场景分布，并补充实际城墙样本。

实际权重、训练记录、测试集指标和样例检测图是模型验收的必要交付。仓库中的模型适配器与训练命令不能代替这些产物。

当前可转换的样本为 942 张：训练集 759 张、验证集 97 张、测试集 86 张。原始标注中有 6 个图片引用无法匹配，134 个尺寸不一致的样本需要人工核对，1 个无效框被排除。上述统计描述数据转换结果，不是模型评估指标。

软件验收证据包括四端运行截图、角色与状态用例、图片和报告样本、模型实验数据及设备测试记录。论文、开题材料、文献综述、外文翻译、答辩演示与学校表单需依据学校模板组织。教师评语、答辩记录、签字、成绩、查重报告只能由实际流程产生，不能由软件自动填造。
